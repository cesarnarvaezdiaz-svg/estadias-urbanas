# Estadías Urbanas

Este repositorio conserva la web v10 original y agrega el proyecto móvil en una carpeta independiente.

## Contenido

- `estadiasurbanas_v10.zip`: respaldo original de la web.
- `app-eurabanas/`: aplicación para Android e iOS construida con React Native, Expo SDK 57, TypeScript y Expo Router.

La app no usa WebView ni una base de datos separada. Consume la API PHP de Estadías Urbanas y comparte usuarios, reservas, puntos, disponibilidad y estados de pago con la web.

Consulta [la guía de la aplicación](app-eurabanas/README.md) para instalarla y ejecutar sus verificaciones.
